# Code Syntax Highlighting & Block Chrome Contract

**Feature**: `017-streaming-render-code-polish`  
**Date**: 2026-11-14  

This contract defines the syntax highlighting standards, language aliases, DOM structure, and interaction behavior for code blocks rendered in `e-webui`.

---

## 1. Supported Language Grammars & Normalization

The vendored syntax highlighter (`app/static/vendor/prism.min.js`) supports the following language aliases:

| Language | Recognized Aliases | Grammar Loaded | Fallback If Missing |
|---|---|---|---|
| Python | `python`, `py` | `Prism.languages.python` | Escaped Plain Text |
| JavaScript | `javascript`, `js` | `Prism.languages.javascript` | Escaped Plain Text |
| TypeScript | `typescript`, `ts` | `Prism.languages.typescript` | JavaScript |
| Bash / Shell | `bash`, `sh`, `shell`, `zsh` | `Prism.languages.bash` | Escaped Plain Text |
| JSON | `json` | `Prism.languages.json` | Escaped Plain Text |
| YAML | `yaml`, `yml` | `Prism.languages.yaml` | Escaped Plain Text |
| HTML / Markup | `html`, `xml`, `svg`, `markup` | `Prism.languages.markup` | Escaped Plain Text |
| CSS | `css` | `Prism.languages.css` | Escaped Plain Text |
| SQL | `sql` | `Prism.languages.sql` | Escaped Plain Text |
| Markdown | `markdown`, `md` | `Prism.languages.markdown` | Escaped Plain Text |

---

## 2. Code Block DOM Structure

All rendered code blocks generated by `markdown.js` MUST adhere to this exact semantic DOM structure:

```html
<div class="code-container" dir="ltr">
  <div class="code-header">
    <span class="code-lang-badge">{safeLang}</span>
    <button class="btn-code-copy" type="button" aria-label="Copy code to clipboard">
      <svg class="i" viewBox="0 0 24 24"><rect x="9" y="9" width="11" height="11" rx="2"/><path d="M5 15V6a2 2 0 0 1 2-2h9"/></svg>
      <span class="copy-label">Copy</span>
    </button>
  </div>
  <pre><code class="language-{safeLang}">{highlightedHtml}</code></pre>
</div>
```

---

## 3. Directional & Monospace Isolation

1. Regardless of whether surrounding text or paragraph is RTL (Persian / Arabic) or LTR, the code block container MUST enforce `dir="ltr"` and `unicode-bidi: isolate`.
2. Fonts MUST strictly bind to `var(--font-mono)` (`"JetBrains Mono", ui-monospace, monospace`).

---

## 4. Clipboard Copy Interaction Rules

1. When `.btn-code-copy` is clicked, the application copies the **raw unhighlighted code text** (`element.textContent` or stored string) to `navigator.clipboard`.
2. Upon successful copy, the button text changes to `"Copied!"` and the copy icon transitions to a checkmark SVG.
3. After exactly 2,000 ms, the button reverts to `"Copy"` and the original icon.
4. Copy handlers MUST be idempotent and safe against repeated calls (`data-copy-bound="true"`).
