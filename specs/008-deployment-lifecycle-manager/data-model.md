## 1. Filesystem Entities & Layout

The deployment lifecycle manager enforces a strict, isolated layout inside the container at `/opt/e-webui/`:

```text
/opt/e-webui/
├── current -> releases/<active-release-id>
├── releases/
│   ├── <release-id>/
│   │   ├── app/                      # Application source code
│   │   │   ├── main.py
│   │   │   ├── config.py
│   │   │   └── ...
│   │   ├── requirements.txt          # Release dependency specification
│   │   ├── venv -> ../../venvs/<hash> # Symlink to matching virtualenv
│   │   ├── data -> ../../shared/data # Symlink to persistent storage
│   │   └── release_metadata.json     # Release-level metadata
│   └── ...
├── venvs/
│   ├── <requirements-hash>/          # Python virtualenv keyed by SHA-256 of requirements.txt
│   │   ├── bin/                      # Python & uvicorn binaries
│   │   └── lib/                      # Installed site-packages
│   └── ...
├── shared/
│   ├── .env                          # User & runtime environment variables
│   └── data/                         # Persistent databases, uploads, user content
├── staging/                          # Ephemeral staging for archives during transfer
│   └── release-<release-id>.tar.gz
├── deployment.env                    # Host-managed proxy & port configuration
├── .deploy_state                     # Structured JSON tracking deployment lifecycle
└── .deploy.lock                      # Exclusive concurrency lock (directory/file)
```

## 2. Entity Specifications

### 2.1 Release

Represents an immutable, standalone version of the e-webui application.

| Field | Type | Description |
|---|---|---|
| `release_id` | String | Unique identifier formatted as `YYYYMMDD-HHMMSS` or commit hash (e.g., `20261106-210000`). |
| `path` | Path | Absolute path: `/opt/e-webui/releases/<release_id>`. |
| `requirements_hash` | String (Hex 64) | SHA-256 checksum of `requirements.txt`. |
| `venv_path` | Path | Target of symlink: `/opt/e-webui/venvs/<requirements_hash>`. |
| `data_path` | Path | Target of symlink: `/opt/e-webui/shared/data`. |
| `created_at` | ISO 8601 UTC | Timestamp of package extraction and staging. |
| `status` | Enum | `staged`, `active`, `retained`, `failed`. |

---

### 2.2 Dependency Environment (Virtualenv)

Represents an isolated Python execution environment.

| Field | Type | Description |
|---|---|---|
| `hash` | String (Hex 64) | SHA-256 digest of `requirements.txt`. |
| `path` | Path | `/opt/e-webui/venvs/<hash>`. |
| `python_version` | String | Python runtime version (e.g., `3.11` or `3.13` from base OS). |
| `installed_at` | ISO 8601 UTC | Timestamp when packages were installed via pip. |
| `ref_count` | Integer | Number of active or retained releases referencing this virtualenv. |

### 2.4 Deployment Configuration (`deployment.env`)

Stores operational host-mapping configuration at `/opt/e-webui/deployment.env`.

```bash
# Generated by e-webui deploy.sh
CONTAINER_NAME="e-webui-app"
HOST_PORT="8080"
APP_PORT="8080"
APP_HOST="0.0.0.0"
OLLAMA_HOST="http://127.0.0.1:11434"
DEPLOYMENT_VERSION="2.0.0"
```

### 2.5 State Transitions

```text
[No Deployment] 
       │
       ▼ (./deploy.sh --install)
[Initial Staging] ───(Health OK)───► [Active: Release 1]
                                            │
                                            ▼ (./deploy.sh --update)
                                    [Staging Release 2]
                                            │
                        ┌───────────────────┴───────────────────┐
                        ▼                                       ▼
                  (Health OK)                              (Health Fail)
                        │                                       │
                        ▼                                       ▼
               [Active: Release 2]                    [Automatic Rollback]
           (Previous: Release 1)                                │
                                                                ▼
                                                       [Active: Release 1]
                                                    (Failed Release 2 kept)
```
