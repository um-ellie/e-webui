# Systemd Service Unit Contract

**Feature**: `014-provision-kokoro-tts` | **Date**: 2026-11-07 | **Spec**: [spec.md](../spec.md)

This contract defines the systemd service unit template rendered and installed at `/etc/systemd/system/e-webui.service`.

---

## Unit File Template

```ini
[Unit]
Description=e-webui Application Service with Kokoro TTS Support
After=network.target network-online.target
Wants=network-online.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/e-webui/current
ExecStart=/opt/e-webui/current/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port ${APP_PORT}
Restart=always
RestartSec=3

# Persistent and Deployment Environment Configuration
EnvironmentFile=-/opt/e-webui/deployment.env
EnvironmentFile=-/opt/e-webui/shared/.env

# Default Fallback Environment
Environment="PYTHONPATH=/opt/e-webui/current"
Environment="APP_HOST=0.0.0.0"
Environment="APP_PORT=${APP_PORT}"
Environment="OLLAMA_HOST=${OLLAMA_HOST}"

# Offline Model Runtime Configuration
Environment="HF_HUB_OFFLINE=1"
Environment="TRANSFORMERS_OFFLINE=1"
Environment="HF_DATASETS_OFFLINE=1"
Environment="KOKORO_MODEL_DIR=/opt/e-webui/shared/models/kokoro"

# Audio Phonemization Environment
Environment="ESPEAK_DATA_PATH=/usr/lib/x86_64-linux-gnu/espeak-ng-data"

# Security Hardening
NoNewPrivileges=true
PrivateTmp=true

[Install]
WantedBy=multi-user.target
```

---

## Deployment Environment File (`/opt/e-webui/deployment.env`)

During provisioning, `scripts/deploy.sh` writes or updates `/opt/e-webui/deployment.env`:

```bash
# Generated by e-webui deployment lifecycle manager
APP_PORT=8080
OLLAMA_HOST=http://127.0.0.1:11434
KOKORO_MODEL_DIR=/opt/e-webui/shared/models/kokoro
HF_HUB_OFFLINE=1
TRANSFORMERS_OFFLINE=1
```
