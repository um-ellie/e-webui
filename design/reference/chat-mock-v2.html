How do I follow the Ollama logs from the host when it runs inside an Incus container?
Thought for 4 seconds
Searched 3 docs

Use incus exec to run journalctl inside the container. Ollama logs to the systemd journal, so you can follow it live:

bashCopy
# follow logs live
incus exec ollama -- journalctl -u ollama -f
# last 100 lines only
incus exec ollama -- journalctl -u ollama -n 100

If the GPU looks idle, add OLLAMA_DEBUG=1 to the service environment and restart it
